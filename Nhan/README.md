## 📌 Giới thiệu

Thư mục này được sử dụng làm không gian riêng để lưu trữ, sáng tác và trình bày **các câu chuyện cười, tiểu phẩm hài hước dưới định dạng HTML**. 

Khác với văn bản thuần túy, việc thể hiện bằng HTML giúp các câu chuyện trở nên sinh động, trực quan và hấp dẫn hơn thông qua:
- 🎨 Giao diện tùy biến, màu sắc, font chữ và phong cách trình bày đẹp mắt.
- 🖼️ Tích hợp hình ảnh minh họa, meme, GIF vui nhộn.
- 🎬 Nhúng video, âm thanh, hiệu ứng tiếng cười sống động.
- ⚡ Các tính năng tương tác (nút bấm, hiệu ứng chuyển động, câu đố / plot twist ẩn hiện).
