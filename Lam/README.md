# 🍃 Kho Truyện Cười (HTML) - Lam

Chào mừng bạn đến với thư mục lưu trữ và sáng tác truyện cười của **Lam**!

---

## 📌 Giới thiệu

Thư mục này được sử dụng làm không gian riêng để lưu trữ, sáng tác và trình bày **các câu chuyện cười, kỷ niệm đời thường vui nhộn dưới định dạng HTML tương tác**.

Khác với văn bản thuần túy, việc thể hiện bằng HTML giúp các câu chuyện của Lam trở nên sống động, gần gũi và hấp dẫn hơn qua:
- 🎨 Giao diện tùy biến theo phong cách tươi sáng, ấm áp và hiện đại.
- 🖼️ Tích hợp truyện tranh 4 khung (4-Koma), tranh đơn và chế độ xem webtoon / slideshow.
- 🎧 Hiệu ứng âm thanh cơ khí và nhạc vui nhộn bằng công nghệ Web Audio (không cần tải file ngoài).
- 💖 Các nút bấm thả cảm xúc, tương tác trực tiếp và phóng to ảnh nét căng.

```text
Lam/

├── images/                                  # Hình ảnh minh họa truyện tranh

└── co_ket_bung_bau_vao_thanh_giuong_y_te.html # Trang truyện cười HTML tương tác
```

## 🚀 Hướng dẫn xem truyện

- **Cách 1:** Nhấp đúp chuột trực tiếp vào tệp `index.html` hoặc tệp `.html` bất kỳ để mở trên trình duyệt web mặc định (Chrome, Edge, Cốc Cốc, Firefox,...).
- **Cách 2:** Từ trang chủ dự án (`../index.html`), bấm vào thẻ **Kho Truyện Cười HTML - Lam** để vào thẳng cổng truyện.
- **Cách 3:** Dùng tiện ích mở rộng như **Live Server** trên VS Code để có trải nghiệm tốt nhất.
